Levedex — guia e roadmap

Catálogo interativo de 10 cepas de levedura cervejeira, publicado como página HTML autônoma. Este documento cobre o funcionamento atual e possíveis próximos passos.

Como usar

O grid mostra um card por cepa. O único controle de interface é o botão circular (FAB) no canto inferior direito:

  • Filtro — Todas / Grátis / Premium.
  • Ocultar texto — remove nome, fabricante, estilo e valores numéricos, mantendo símbolo de raridade, selo grátis/premium e as barras de estatística. Serve para leitura puramente visual do catálogo.

Como ler um card

  • Selo grátis/premium — grátis = levedura seca, disponível em qualquer loja de insumos (Fermentis, Lallemand). Premium = levedura líquida, cadeia fria, fabricantes especializados (White Labs, Wyeast, Omega, Imperial).
  • Símbolo de raridade — segue a hierarquia atual do TCG Pokémon: ● Comum, ◆ Incomum, ★ Rara, ★★ Dupla Rara, ✦ Ultra Rara, ✦✦ Rara Ilustração, ✦✦✦ Hyper Rara. O tratamento visual do card (borda, gradiente, brilho) acompanha a escala.
  • Barras de Atenuação e Floculação — valor numérico/qualitativo ao lado de cada barra.
  • Modal de detalhes — tocar num card (com o Modo edição desligado) abre o modal com ilustração, estatísticas, temperatura, tolerância a ABV e nota; as setas navegam entre as cepas visíveis e Editar abre o formulário.
  • Ilustração — desenhada em SVG conforme o tipo (sachê para grátis, tubo para premium) e colorida por categoria de estilo. O formulário aceita uma URL de imagem https opcional (campo img no JSON); a página publicada no Claude bloqueia imagens externas, então nela vale o desenho.

Dados: CRUD e importação

  • Modo edição — switch no FAB. Ativo, tocar um card abre o formulário preenchido para editar ou excluir.
  • Adicionar cepa — botão no FAB, abre o mesmo formulário vazio.
  • Campos do formulário — nome, fabricante, estilo, status, raridade, atenuação ("min-max"), floculação (select), ABV, temperatura, nota. Nome/fabricante/estilo são obrigatórios; o resto aceita vazio.
  • Importar JSON — botão no FAB, abre um campo de texto para colar um array de objetos (mesmos campos do formulário, em inglês: name, maker, style, status, tier, atn, floc, abv, temp, note). Cada item vira uma cepa nova, numerada em sequência; não substitui o catálogo existente. Itens com mesmo nome e fabricante de uma cepa já existente são ignorados. O botão "Preencher com as 29 cepas mapeadas" cola no campo o lote conhecido (cepas 011 a 039) para revisão antes de adicionar.
  • Persistência — ao salvar, editar, excluir ou importar, a página republica a si mesma com os dados atualizados (capacidade artifact do runtime de Artifacts). Qualquer pessoa com o link vê a versão mais recente ao recarregar. Sem esse mecanismo (pré-visualização, ou visualizador sem permissão de escrita), as alterações ficam só na aba aberta.
  • Edições simultâneas de duas pessoas não são mescladas: quem publica por último vence, silenciosamente.

Roadmap (possível)

  • Separar os dados das cepas do HTML — resolvido de outro jeito: dados seguem embutidos, mas agora editáveis in-place com persistência via publish; dispensa arquivo externo para esse fim.
  • Persistir filtro e estado de "ocultar texto" — superado: o catálogo inteiro persiste agora, não só preferências de UI.
  • Expandir o catálogo: trapistas belgas (Chimay, Westmalle), blends sour (Lacto + Brett), Ringwood (Wyeast 1187), Kölsch (Wyeast 2565).
  • Alternância manual claro/escuro dentro do próprio FAB, complementando o prefers-color-scheme automático atual.
  • Modo comparação: duas cepas lado a lado.
  • Campo de busca por nome ou estilo — feito: campo no topo do FAB, filtra por nº, nome, fabricante, estilo e nota, sem diferenciar acentos; combina com o filtro grátis/premium.
  • Data de verificação por cepa, para rastrear quando a ficha técnica foi conferida pela última vez.
  • Exportar catálogo atual como JSON, simétrico à importação.
  • Aviso de edição concorrente, já que a publicação mais recente vence sem aviso.
